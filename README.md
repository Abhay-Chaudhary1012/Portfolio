# 🚀 Abhay Chaudhary — Developer Portfolio

A modern, responsive, and recruiter-ready personal portfolio website showcasing my skills, projects, and experience as an aspiring software developer.

> **Live Demo:** [View Portfolio](#) *(deploy link here)*

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Modern UI** | Dark theme with gradient accents, glassmorphism cards, and premium aesthetics |
| 🌊 **Smooth Animations** | Scroll-reveal animations, parallax effects, typing animation, and micro-interactions |
| 📱 **Fully Responsive** | Optimized for desktop, tablet, and mobile devices |
| 🎯 **Project Showcase** | Featured projects with tech stacks, descriptions, and live demo links |
| 📊 **Animated Skill Bars** | Visual progress indicators categorized by Frontend, Backend, and Tools |
| 📬 **Contact Form** | Clean contact section with form and social links |
| 🖱️ **Interactive Elements** | Cursor glow, 3D card tilt, hover effects, and animated counters |
| ⚡ **Performance** | No heavy frameworks — pure HTML, CSS, and JavaScript |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Flexbox, Grid, animations
- **JavaScript (ES6+)** — Intersection Observer, DOM manipulation
- **Font Awesome 6** — Icon library
- **Google Fonts** — Inter + Fira Code typography

---

## 📁 Project Structure

```
portfolio/
├── index.html          # Main HTML structure
├── styles.css          # All styling (dark theme, responsive)
├── script.js           # Animations, interactions, scroll effects
├── README.md           # Project documentation
└── assets/             # Images and media (optional)
    ├── screenshots/
    └── resume/
```

---

## 🖥️ Sections

1. **Hero** — Animated intro with headline, CTA buttons, and tech stack icons
2. **About** — Professional bio with animated stat counters
3. **Skills** — Categorized (Frontend / Backend / Tools) with animated progress bars
4. **Projects** — 3 featured projects with descriptions, tech stacks, and links
5. **Contact** — Form + email, GitHub, LinkedIn links
6. **Footer** — Social links and copyright

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Abhay-Chaudhary1012/portfolio.git

# Open in browser
cd portfolio
open index.html
# Or use Live Server in VS Code
```

No dependencies to install — it's pure HTML/CSS/JS!
